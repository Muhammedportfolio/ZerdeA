# ZerdeAI — восстановленный проект для Codex

Это редактируемый Java 17 проект, восстановленный из вашего установщика. Это не оригинальные исходники: имена локальных переменных и структура кода частично восстановлены декомпилятором. Ошибки восстановления, мешавшие компиляции, исправлены. Оригинальный JAR сохранён в baseline для сравнения.

## Что делать на Windows

1. Распакуйте ВЕСЬ архив в отдельную папку, например C:\Projects\ZerdeAI_Project. Не запускайте файлы прямо внутри ZIP.
2. Откройте эту папку в установленном Codex.
3. Передайте Codex задачу, опираясь на карту проекта и правила работы ниже.
4. Для запуска готовой программы: START_WINDOWS.bat. Для сборки: BUILD_PROJECT.cmd. Для проверок: TEST_PROJECT.cmd.

Java runtime, библиотеки и облачный туннель взяты из установщика. Runtime предназначен для запуска приложения. Для сборки исходников нужен полный JDK 17 с компилятором; если bundled runtime не содержит `jdk.compiler` и `jdk.jartool`, задайте `JAVA_HOME` на установленный JDK перед запуском команд сборки и тестов.

Если PowerShell заблокирован политикой организации, не отключайте её: попросите Codex собрать проект командами Java из scripts/build.ps1 или использовать установленный JDK 17. Не отключайте Windows Defender.

## Данные и база

Рабочие данные находятся отдельно: %USERPROFILE%\EduTestSuite2. В архив НЕ включены данные с вашего компьютера. Скрипты сборки эту папку не изменяют. Тесты используют временные базы.

Перед изменениями установленной программы: закройте её и сохраните копию всей папки EduTestSuite2 на своём ПК. Не передавайте эту копию посторонним: она может содержать учётные записи и секреты.

### Режимы базы данных: H2 и Supabase Free (бета, 11.11.2026)

- **H2** остаётся режимом по умолчанию: локальные данные и работа без интернета сохраняются.
- Добавлена опция **Supabase PostgreSQL** для общего сервера. В интерфейсе преподавателя название выбранной базы отображается в разделе подключения устройств.
- В бесплатной организации `zerde ai` создан проект `zerdeai-shared` (`ap-south-1`), добавлена закрытая схема `zerdeai.records` с RLS. Таблица не открыта через публичный Data API. В проверке схемы Supabase Security/Health advisories ошибок не нашли.
- Сервер использует PostgreSQL JDBC по TLS (`sslmode=verify-full`). Студенческий клиент обращается к API ZerdeAI; пароль базы остаётся на доверенном компьютере сервера и не включается в ZIP/EXE.
- Для подключения создайте отдельную роль PostgreSQL с членством в `zerdeai_backend` по `SUPABASE_MIGRATION_RU.md`, затем дважды щёлкните `START_SUPABASE.bat`. Он оставляет окно PowerShell открытым и задаёт ExecutionPolicy только для этого процесса. URL и логин вводятся в окне PowerShell, пароль — скрыто. Скрипт хранит их только в памяти процесса. Ошибка подключения не включает H2 автоматически.
- **Перенос H2:** отдельная утилита делает проверку и backup по типам записей, сверяет ID и связи, импортирует только в пустую таблицу без перезаписи и перечитывает строки после нового JDBC-соединения. Прежде чем переключать сервер, запустите `scripts/supabase-migration.ps1` и изучите `SUPABASE_MIGRATION_RU.md`.
- **Бета на 11.11.2026:** перенос локальных данных в отдельный Supabase-проект выполнен с резервной копией, сверкой количества записей и связей; исходная база H2 сохранена. Запуск ZerdeAI с Supabase дошёл до окна входа. Полная проверка создания/изменения данных и повторного чтения после перезапуска приложения ещё не завершена. Для запуска используйте `START_SUPABASE.bat` после настройки роли PostgreSQL. Не используйте бета-базу как единственную копию данных.
- **Приватность:** база, backup с записями и пароли не входят в GitHub, ZIP или EXE. Не публикуйте JSON backup. Импортёр принимает только пустую облачную таблицу и остановится при повторном запуске на уже заполненном проекте.
- Это Supabase **Free**, без платных дополнений. У бесплатного плана ограничены ресурсы и неактивные проекты могут приостанавливаться. Перед общим использованием проверьте актуальные лимиты [Supabase Free](https://supabase.com/pricing) и политику [приостановки неактивных проектов](https://supabase.com/docs/guides/platform/going-into-prod#pausing-and-restoring-projects).

## Что проверено

Все исходники компилируются для Java 17. Из итогового JAR прошли:

- SuiteTest: 43 проверки;
- HttpTest: 8;
- PersistenceTest: 33;
- GoogleLinkTest: 16 (имитация провайдера);
- TunnelTest: 11 (тестовые дочерние процессы);
- LaunchTest: 3 сценария запуска;
- SupabaseMigrationTest: 4 проверки безопасного экспорта и отказа от перезаписи.

Итого 115 проверок и 3 сценария запуска. Дополнительно проверяются передача аватара собеседнику в чате и сохранение заголовка диалога тьютора из первого вопроса. PersistenceTest также включает доступность преподавателя только после назначения ученика в его группу, приватность чатов, идемпотентную отправку, назначение курсов, прогресс урока, защиту тьютора, резервное копирование новых записей и сохранение после перезапуска. SupabaseMigrationTest использует только временный H2 и проверяет экспорт, отказ от автопереключения на H2 и запрет перезаписи backup. После декомпиляции остаются предупреждения unchecked.

Не проверены: установка/обновление/удаление через интерфейс Windows, реальный облачный вызов ИИ, реальный Google OAuth, внешний Cloudflare-туннель, исполнение Docker и нагрузка многих студентов. Тесты не доказывают полную идентичность исходному приложению.

Первый обязательный этап в Codex — воспроизвести сборку, проверки и ручной запуск в вашей Windows-среде. Не начинайте с полного переписывания программы.

## Настройки вида и поставка Windows

В профиле можно выбрать светлую, тёмную тему или тему системы и уменьшить анимацию. Выбор сохраняется в браузере/WebView отдельно от учётной записи. Тема применяется до загрузки стилей; системное `prefers-reduced-motion` также учитывается. Ответы теста выделяются с клавиатуры и мышью без показа правильности.

Исходники мастера находятся в `Install-ZerdeAI.ps1`, `scripts/uninstall.ps1` и `scripts/SetupBootstrap.cs`. Установщик рассчитан на текущего пользователя: при первой установке предлагает «Установить», при повторной — «Обновить», «Запустить» и «Удалить». Удаление оставляет `%USERPROFILE%\EduTestSuite2`; полный вариант включается отдельной выключенной галочкой и требует подтверждения. Обновление копирует файлы программы поверх предыдущих, не удаляя каталог пользовательской базы. Текущая версия — 2.3.0.

Сборка установщика на Windows с .NET Framework 4.x: `powershell -ExecutionPolicy Bypass -File scripts\build-installer.ps1 -OutputDirectory ..\..\outputs`. Скрипт включает ZIP проекта и окно установки в EXE. Параметр `-UseIExpress` включает IExpress вместо встроенного bootstrapper. В этой среде окно IExpress сообщило `Unable to open the Report file`; создание Setup EXE выполнено альтернативным bootstrapper. Полный цикл установки, обновления и удаления через настройки Windows не проверялся.

Архив исходного проекта содержит полный JDK не включён: для сборки Java-исходников нужен JDK 17 с `javac` и `jar` (укажите его через `JAVA_HOME`). Комплектный runtime предназначен для запуска приложения и в этой копии не содержит модулей `jdk.compiler` и `jdk.jartool`.

Состояние подготовки и ограничения записаны в `verification/CODEX_WORK_LOG_2026-11-10.txt`. Публичная версия не содержит паролей, ключей доступа или пользовательской резервной копии. Версия с Supabase — бета от 11.11.2026; настройка отдельной роли и полноценная проверка операций приложения после перезапуска остаются обязательными шагами.
