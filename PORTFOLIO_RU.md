# ZerdeAI — история разработки для портфолио

## О проекте

ZerdeAI — учебное приложение для преподавателей и студентов. Оно объединяет группы, задания, сохранение попыток и оценок, библиотеку материалов и коммуникацию. Есть русская и казахская локализации.

Проект начался с готового Windows-установщика, а не с чистого репозитория исходников. Java-код частично восстановлен из установленного приложения; поэтому это восстановленная и доработанная версия, а не оригинальные исходники автора. Исходный JAR сохранён в `baseline/` как бинарный эталон.

## Как выполнялась работа

1. **Инвентаризация и восстановление.** Проверены структура установленного приложения, ресурсы, библиотеки, точки запуска и локальная база. Для сравнения оставлена исходная бинарная версия.
2. **Восстановление сборки.** Исходники приведены к сборке на Java 17. Настроены команды сборки, запуска и тестирования для Windows.
3. **Сохранение локальных данных.** H2 оставлена основным автономным режимом. Учётные записи, группы, задания, попытки и оценки остаются серверными данными; тесты работают на временных базах.
4. **Серверные функции.** Добавлены хранимые чаты, курсы, прогресс уроков и история ИИ-тьютора. Сервер проверяет принадлежность чатов, групп и курсов пользователю.
5. **Интерфейс.** Доработаны навигация, страницы материалов, курсов и чатов, русские и казахские строки, светлая и тёмная темы, состояния ответов в результатах и объяснения пустых состояний.
6. **Упаковка.** Подготовлены сборочный сценарий проекта и Windows Setup с вариантами установки, обновления, запуска и удаления. Пользовательские данные хранятся отдельно от каталога программы.
7. **Проверки.** Выполнены 111 автоматических проверок и 3 сценария запуска, проверка JavaScript и визуальные проверки страниц в браузере.

## Технологии и устройство

- **Java 17** — серверная логика, HTTP API и запуск приложения.
- **JavaFX/WebView** — Windows-оболочка приложения.
- **H2** — локальное хранение данных.
- **HTML, CSS, JavaScript** — веб-интерфейс, который использует сервер.
- **GitHub Release** содержит полный ZIP проекта и Windows Setup; архив включает исходники, ресурсы и необходимые зависимости.

- Supabase не подключён; документ миграции — план, а не действующая облачная синхронизация.
- Учебная база остаётся локальной на компьютере-сервере.

- Некоторые возможности курсов, в том числе загрузка видео, требуют дальнейшей разработки.

## Сборка на Windows

1. Распакуйте `ZerdeAI_Project.zip` в отдельную папку.
2. Установите полный JDK 17 и задайте `JAVA_HOME`, если используемая Java-среда не содержит компилятора.
3. Запустите `TEST_PROJECT.cmd` для сборки и тестов.
4. Запустите `BUILD_PROJECT.cmd` для сборки приложения.
5. Для запуска готового Windows-приложения используйте `START_WINDOWS.bat`.

Подробности и предупреждения о данных находятся в `README_RU.md`, схема модулей — в `PROJECT_MAP_RU.md`.
