# Журнал изменений ZerdeAI

## 2.3.0 Beta — 11 ноября 2026 · Supabase

- Добавлен бета-режим общей базы Supabase PostgreSQL; локальная H2 остаётся значением по умолчанию и работает без интернета.
- Добавлены серверный JDBC-адаптер с проверкой TLS, запуск через `START_SUPABASE.bat` и отдельная роль базы. Пароль запрашивается скрыто при запуске, не хранится в исходниках и не включён в публичную поставку.
- Добавлена утилита переноса H2 с резервной копией, предварительной проверкой связей, импортом без перезаписи и сверкой записей.
- Подготовлены SQL-миграция для закрытой схемы с RLS и документация настройки Supabase Free.
- Перенос данных пользователя выполнен отдельно с резервной копией и сверкой количества записей и связей. H2-копия сохранена.
- Проверка на ПК: запуск с Supabase дошёл до окна входа. Полная проверка создания/изменения данных и их повторного чтения после перезапуска приложения ещё не завершена; поэтому выпуск помечен Beta.
- Предыдущая версия 2.2.1 и её исправления остаются в истории ниже.

## 2.2.1 — 10 ноября 2026

- Исправлено отображение фото профиля собеседника в списке диалогов и заголовке чата.
- Исправлена высота окна переписки: история прокручивается отдельно, строка ввода остаётся доступной.
- В обычных элементах интерфейса имя сокращено до имени и фамилии; полное ФИО остаётся в личной информации.
- Диалоги ИИ-тьютора в истории называются по первому вопросу, сообщения показываются в хронологическом порядке — ответ под вопросом.
- Скрыта полоса прокрутки бокового меню, которая перекрывала меню аккаунта; прокрутка меню навигации сохранена.
- Установщик собирается без локального JDK и тестовых файлов. Данные пользователя остаются отдельно от программы при обновлении и обычном удалении.

### Проверки

- Все 111 проверок в пяти наборах пройдены; дополнительно пройдены 3 сценария запуска.
- Сборка Java 17, синтаксис `web/app.js` и `git diff --check` прошли.
- Проверки используют временную H2-базу; облачные API проверяются с имитацией провайдера.

### Ограничения

- Supabase не подключён; приложение работает с локальной H2.
- Полный цикл установки, обновления и удаления через системный интерфейс Windows не проходил автоматизированную проверку.
